# FonoApoio UBS

Projeto PWA sem fins lucrativos para apoiar profissionais, famílias e UBS no acesso a atividades de fonoaudiologia infantil.

## Princípios
- Não diagnosticar.
- Não substituir avaliação ou atendimento profissional.
- Priorizar evidências, revisão profissional, acessibilidade e privacidade.
- Não usar dados reais de crianças durante o desenvolvimento inicial.
- Desenvolver offline-first para contextos de conectividade limitada.

## Primeira versão
- Tela inicial com perfis.
- Minha Jornada.
- Área da Família.
- Área do Profissional.
- Biblioteca científica.
- PWA instalável e funcionamento básico offline.

## Próximos passos
1. Revisão da arquitetura e acessibilidade.
2. Biblioteca de atividades com referências e responsável pela revisão.
3. Autenticação e perfis com proteção de dados.
4. Armazenamento seguro e sincronização offline.
5. Piloto controlado com profissionais voluntários antes de uso em UBS.

**Importante:** conteúdo clínico deve passar por revisão de profissionais habilitados antes de uso assistencial.
